Feed format prototypes

Desktop-focused alternatives to the current “one big card of rows” middle column. Same sample content in every format. Dividers stay; container chrome is what changes.

Left rail Federal control

Timeline

Current. One 16px rounded card wraps the whole list. On desktop between two rails this reads as a floating slab — the clunky “semi-card” feel.

    Open stream. Drop the outer card entirely. Rows sit on the page background with full-width hairline dividers. Closest fix to the lumpiness without changing information density.

      Date rail. Still open (no card), but dates move into a left gutter. Scannable like a wire/AP timeline; topic + meta get more horizontal room.

        Compact scanner. Two-line rows (headline + meta only). No teaser until expand. Highest throughput; best if the feed feels too tall/chatty on desktop.

          Soft bands. No outer card; light alternating row wash + inset hairlines. Slightly more “list of moments” than “one panel.” Keep if you want a little surface without the big rounded box.

            Right rail Pulse

            Recommendation to try first

            1. B · Open stream — smallest change, biggest clunk reduction. Same content, same dividers, no slab.
            2. C · Date rail — if open stream still feels flat, add structure via the date gutter (very editorial, fits the design language).
            3. Skip true individual cards; they usually make desktop denser and noisier than the current problem.
